# Dashboard concept demos

These prototypes explore dashboard improvements without importing or changing NeXroll's production React code.

- `focus.html` prioritizes “Now showing,” the upcoming schedule, and actionable system health. It is intended as the friendlier default dashboard.
- `operations.html` preserves the current dashboard's information density while grouping tiles by Automation, Content, and Services.
- `focus-enhanced.html` is an interactive evolution of the Focus concept. Users can drag and resize tiles, choose visible cards and detail levels, apply presets, change density, and persist their demo layout in the browser.

All concepts reuse representative values from the current dashboard screenshot and NeXroll's existing dark visual language. The original two concepts remain static; the enhanced concept includes simulated actions and functional customization controls.
