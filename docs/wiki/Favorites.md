# Favorites

> Available from 2.2.0.

Open a page you use often, then click the **star beside Favorites** in the sidebar. The page appears under Favorites as a shortcut. Open a favorite and click the filled star to remove it.

Favorites use the same navigation as the rest of NeXroll. They also work in the collapsed sidebar and the mobile navigation drawer; selecting one closes the mobile drawer.

Your Favorites are saved on the NeXroll server for your signed-in user and follow that user across browsers and devices. Another user has their own list. Without sign-in, the instance has one shared list. Reload or return focus to the window to refresh changes made elsewhere. If saving fails, the previous list remains and the sidebar shows an error.

Favoriting a page saves a shortcut, not its current search/filter selections or an unsaved schedule/sequence. It does not change page permissions.
